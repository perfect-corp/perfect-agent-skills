# YouCam AI Agent plugin package

This is the reusable plugin package for YouCam AI Agent. It contains the shared
skills and MCP registration used by supported agent hosts:

- `.claude-plugin/plugin.json` for Claude plugin metadata and skill registration
- `.mcp.json` for the remote YouCam AI Agent MCP server
- `skills/youcam-ai-agent/` for workflow instructions and error recovery
- `SETUP.md` for OAuth connection guidance

See the [repository README](../../README.md) for installation and usage.
